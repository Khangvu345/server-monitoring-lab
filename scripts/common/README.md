# Common setup

Để trống trong giai đoạn đầu. Sau khi nhóm tổng hợp các thiết lập dùng chung, bổ sung script nền tại đây.

Các nội dung dự kiến: package tiện ích chung, timezone, đồng bộ thời gian, SSH, tài khoản/quyền quản trị và thiết lập nền khác. Hostname, IP và firewall cần tham số/cấu hình theo từng VM.
