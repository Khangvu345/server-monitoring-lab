# Server setup

Đặt script cài đặt Nginx, Node Exporter và process-exporter tại đây. process-exporter bắt buộc phải có vì đề tài yêu cầu thu metrics theo từng tiến trình, phần Node Exporter không cung cấp.

Khi bàn giao cần ghi: phiên bản, nguồn cài đặt, checksum (nếu tải binary), lệnh cài, file cấu hình, systemd unit, cổng sử dụng và lệnh xác minh.
