# Benchmark

- `k6/`: kịch bản tải và cấu hình mức tải.
- `results/`: kết quả chạy thực tế (CSV/JSON/log), chỉ thêm dữ liệu đã được rà soát.
- `analysis/`: phân tích throughput, response time, error rate và metrics hệ thống.

Mỗi lần chạy cần ghi: ngày giờ, cấu hình Host/VM, phiên bản phần mềm, mức tải, thời lượng, số lần lặp và điều kiện thử nghiệm.
